# rsml

a small, self-hosted mailing list system.

## usage

```sh
  $ pip install -e . # install the dependencies
  $ cp rsml.toml.example rsml.toml # edit server_secret, etc.
  $ rsml http # start the http server
  $ rsml lmtp # start the lmtp server
```
